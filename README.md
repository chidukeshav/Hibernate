# Hibernate – Java ORM Framework

## 📌 About This Repository

This repository contains my **Java Hibernate practice programs and learning materials**. I am learning Hibernate ORM to understand how Java applications interact with relational databases using object-relational mapping.

## 🚀 Technologies Used

- Java
- Hibernate ORM
- JDBC
- MySQL
- Maven
- Eclipse IDE

## 📚 Topics Covered

- Introduction to Hibernate
- Hibernate Architecture
- ORM (Object Relational Mapping)
- Hibernate Configuration
- Hibernate Mapping
- Entity Classes
- Hibernate SessionFactory
- Session and Transaction Management
- CRUD Operations
  - Create
  - Read
  - Update
  - Delete
- HQL (Hibernate Query Language)
- Database Connectivity
- Hibernate Annotations

## 🎯 Learning Objectives

- Understand Hibernate ORM concepts.
- Connect Java applications with MySQL databases.
- Perform database operations using Hibernate.
- Reduce JDBC boilerplate code.
- Understand entity mapping and persistence.
- Develop Java backend development skills.

## ⚙️ Requirements

- Java JDK
- Eclipse IDE or IntelliJ IDEA
- MySQL Server
- Hibernate ORM
- Maven

## ▶️ How to Run

1. Clone this repository.
2. Open the project in Eclipse or IntelliJ IDEA.
3. Configure MySQL database connectivity.
4. Add the required Hibernate dependencies.
5. Run the Java application.
